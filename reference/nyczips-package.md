# nyczips: superseded by nycmaps

The objects this package used to provide, `nyc_zip_sf` (212 ZIP code
tabulation areas) and `nyc_zips` (ZIP code to borough), are in the
nycmaps package, with the same contents. Use `nycmaps::nyc_zip_sf` and
`nycmaps::nyc_zips`. The nycmaps version of `nyc_zip_sf` is in EPSG:2263
(NAD83 / New York Long Island, ftUS); the copy formerly here was in
EPSG:4269.

## Details

The objects were removed so that loading both packages no longer masks
one copy with the other.
